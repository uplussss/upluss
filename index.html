使用前先了解

  • API 授权建议只开启交易权限，不开启提币权限。
  • 量化策略用于按规则执行交易，不代表稳赚或保本。
  • 建议先用小资金测试，理解策略逻辑和风险后再决定配置。

风险提示：数字资产交易存在市场波动和亏损风险。UPlus 不承诺收益，不提供保本承诺，历史表现不代表未来结果。
